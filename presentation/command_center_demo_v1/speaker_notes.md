# 50-second demonstration narration

**0–14 seconds — Dispatch**

This is our robot command center. We choose a task, a decision method, and automatic or human replies. Here, I launch four different tasks, each running in its own PyBullet world.

**14–33 seconds — Observe and answer**

The cameras show what each robot is doing. When information is missing, questions appear in the queue on the right. I type my answer here. Only the asking robot pauses; the others keep working. After submission, that robot continues.

**33–46 seconds — Continue execution**

We can therefore supervise several tasks from one screen, stepping in when needed. The final status comes from physical checks, rather than the model simply claiming success.

**46–50 seconds — Results**

All four tasks complete in this recorded, time-compressed demonstration.

Presenter cue: point to the right-hand queue during the three typed replies. Navigation uses fully disclosed information and NoAsk, so it correctly has no question. This is an interactive demonstration on one computer, not evidence of two-computer deployment or a paired performance comparison.
