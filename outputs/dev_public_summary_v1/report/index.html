Decision: retain the frozen version

漏问减少与提前询问同时发生。按预先锁定的规则，两个候选版本均不自动晋升为正式配置。

全公开双容器案例还出现了 DeepSeek 反复搬动方块的规划问题。原版达到动作上限失败；摘要版同样达到上限，但最终物理状态满足任务，仍按真实状态计成功。完成率差异不能全部归因于 Jev Gate。
